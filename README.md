# SteadyTeller Frontend

학습 목표, AI 태스크, 학습 일정과 수행 통계를 관리하는 SteadyTeller 프론트엔드입니다.

## 실행

```bash
npm install
npm run dev
```

환경 변수는 `.env.example`을 참고합니다. 실제 API 키나 비밀번호는 저장소에 올리지 않습니다.

## 검증

```bash
npm test
npm run build
```

## 화면 구성

| 메뉴 | 역할 |
| --- | --- |
| 대시보드 | 오늘의 학습과 실행할 일정을 확인합니다. |
| 내 학습 | 확정된 학습 일정과 수행할 태스크를 확인합니다. |
| 학습 관리 | 목표 생성·수정·삭제와 태스크·일정을 관리합니다. |
| 기록 | 학습 수행 이력과 완료율·학습 시간 통계를 확인합니다. |
| 내 정보 관리 | 프로필과 계정 보안 설정을 관리합니다. |

## 공통 레이아웃

- `src/layout/AppLayout.jsx`: 상단 메뉴, 현재 목표 선택, 반응형 모바일 메뉴와 페이지 콘텐츠 영역
- `src/styles/design-tokens.css`: 공통 색상, 간격 기준, 모서리와 그림자 값
- `src/styles/common-layout.css`: 공통 레이아웃과 반응형 스타일

페이지별 기능은 `AppLayout`의 `children` 영역에서 구현합니다. 공통 메뉴나 디자인 토큰을 수정해야 할 때는 다른 페이지에 미치는 영향을 먼저 확인합니다.

## 브랜치 작업 기준

1. 최신 `main`에서 기능 브랜치를 생성합니다.
2. 담당 페이지 내부 기능은 해당 기능 브랜치에서 수정합니다.
3. 공통 레이아웃을 변경해야 한다면 팀에 영향 범위를 먼저 공유합니다.
4. 푸시 전에 테스트와 프로덕션 빌드를 실행합니다.
